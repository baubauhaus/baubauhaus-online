Ein Vorteil beim **BAUHAUS online bestellen** ist die Kombination aus Online-Shop und stationären Fachcentren.

### Online bestellen und liefern lassen

Viele Artikel können direkt über den Online-Shop bestellt und an eine Adresse innerhalb Deutschlands geliefert werden.

Dabei hängt die Versandart vom jeweiligen Produkt ab. Kleinere Artikel werden häufig als Paket verschickt, während schwere oder besonders große Baustoffe per Spedition oder Palette geliefert werden können.

Gerade bei Baustoffen sollte deshalb vor der Bestellung geprüft werden:

* Welche Versandart wird verwendet?
* Wie hoch sind die Versandkosten?
* Wie lange dauert die Lieferung?
* Wird die Ware per Paket oder Spedition geliefert?
* Muss jemand bei der Lieferung anwesend sein?

Bei größeren Bauprojekten können Transportkosten einen erheblichen Teil der Gesamtkosten ausmachen.

## Baumaterial online vergleichen

Vor einer Bestellung sollte nicht ausschließlich der Produktpreis betrachtet werden.

Gerade bei Baumaterial können zusätzliche Faktoren entscheidend sein.

### Preis pro Einheit

Produkte können beispielsweise angeboten werden als:

* Stück
* Paket
* Quadratmeter
* laufender Meter
* Palette
* Bund

Dadurch können zwei zunächst ähnlich wirkende Angebote einen deutlich unterschiedlichen tatsächlichen Preis haben.

### Versandkosten

Bei schweren Baustoffen können Speditionskosten relevant sein.

Ein günstiger Produktpreis bedeutet deshalb nicht automatisch, dass das gesamte Angebot günstiger ist.

### Lieferzeit

Bei einem laufenden Bauprojekt können Lieferzeiten besonders wichtig sein.

Fehlendes Material kann dazu führen, dass Arbeiten unterbrochen werden müssen.

### Technische Eigenschaften

Bei Produkten wie Dämmstoffen, Dachbahnen, OSB-Platten oder Dachsteinen sollten technische Eigenschaften immer berücksichtigt werden.

Dazu gehören beispielsweise:

* Abmessungen
* Materialstärke
* Wärmeleitfähigkeit
* Gewicht
* Belastbarkeit
* Einsatzbereich
* Herstellerangaben
* Verarbeitungshinweise
